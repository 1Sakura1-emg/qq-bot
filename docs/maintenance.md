# 数据与维护

## 不上传的内容

API Key、OneBot 令牌、SSH 私钥、阿里云凭证、管理密码、QQ cookies、登录二维码、QQ 客户端登录目录、聊天记录、记忆数据库、空间发布记录与私人角色配置均不属于公开源码。

`.gitignore` 防止常见运行文件被误加；真实配置请放在被忽略的目录。Git 忽略规则不能代替提交前检查。示例中的账号已替换为 `10000`、`10001`，服务器地址已替换为占位文字。

## 持久数据

AstrBot 数据目录应持续挂载，以下路径相对于 `astrbot-data`：

- `data_v4.db`：AstrBot 对话等运行数据。
- `plugin_data/astrbot_plugin_jinli_memory/memory.sqlite3`：公开和私聊隔离的长期记忆。
- `plugin_data/astrbot_plugin_jinli_qzone/state.json`：每日动态发布尝试和去重记录。
- `plugin_data/astrbot_plugin_jinli_qzone_social/social.sqlite3`：空间评论、回复的持久去重和每日额度。

不要删掉发布或评论记录来强制重试。请求超时可能发生在发布成功之后，自动重试会造成重复。SQLite 备份应使用数据库备份接口或一致性快照，避免在写入期间只复制主文件。

## 空间互动范围

- 只回复启用后别人对她自己近期动态的新评论；每轮最多尝试 2 条，每天最多 20 条。
- 每 180 秒检查一次；读取最近 5 条自己的动态，每条最多检查 40 条一级评论及接口返回的内联回复。
- 「空友爱看」推荐动态：北京时间 09:00–23:00，每天最多 5 条，至少间隔 120 分钟；不保证每天凑满额度。
- 跳过广告、没有可读文字、信息不完整或不适合回复的动态。生成公开评论时不传入私聊记录或长期私聊记忆。
- 使用平台返回的真实评论 ID 和原始推荐对象，不从公开推荐的匿名 UID 猜测 QQ 号。
- 不会自动评论普通好友动态，不会加入他人无关评论对话。

## 资源和已知问题

Compose 记录当前 2 核、约 2 GiB 小服务器的限制；应结合服务器实际资源调整。QQ 登录失效、接口变化或模型服务故障仍可能导致机器人停止回复。

语音识别曾出现 QQ 原生接口错误和超时，尚未确认修复。此前离线语音模型实验导致内存压力，当前未启用，也不包含在本仓库中。不要在小内存服务器上直接恢复旧的 `jinli-asr` 实验服务。

代码推送不触发部署。以后升级插件时应先备份、检查兼容性，再另行安排更新和必要的插件重载；不要直接覆盖整个云端数据目录。
